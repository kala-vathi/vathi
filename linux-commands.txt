	change owner of user and group	
		chown hem:hem f1.txt
		
	Changes the owner of the file f1.txt to the user hemanth12.
	The group ownership remains unchanged.
		chown hemanth12 f1.txt   	
		
	changes only the group ownership of the file f1.txt to the group named hemanth12.
	The user (owner) remains unchanged.
		chown :hemanth12 f1.txt

A hard link is:
Another name for the same original file
Both files share:
Same data
Same inode
Same storage location
Even if original file is deleted → data still exists.

Soft Link (Symbolic Link)
A soft link is:
A shortcut or pointer to another file
It only stores:
Path of original file
If original file is deleted:
soft link breaks

Hard Link	Same person having 2 names
Soft Link	Shortcut icon on desktop
